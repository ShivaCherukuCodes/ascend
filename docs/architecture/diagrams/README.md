# Architecture Diagrams

## Why

Diagrams make system boundaries and responsibilities easier to review than prose alone.

## What

This directory is the only home for source-controlled architecture diagrams. The initial domain-boundary diagram appears in [Domain Model](../domain-model.md).

## How

Use Mermaid where it communicates the architecture accurately. Keep a diagram next to the decision it supports and update it when that decision changes.

## Future Considerations

Add context, container, component, data-flow, and deployment diagrams after their underlying decisions are approved.
