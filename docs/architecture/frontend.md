# Frontend
## Why
The frontend must make a complex personal system feel calm and purposeful.
## What
React and Next.js are planned; the application should use feature-oriented folders and a reusable design system.
## How
Keep routes thin, compose feature modules, and use shared design primitives. Choose state management only for demonstrated cross-feature needs.
## Future Considerations
Define rendering, routing, accessibility, and state policies after the MVP journey is approved.

Human decision required: confirm Next.js usage, rendering needs, and the first user journey.
