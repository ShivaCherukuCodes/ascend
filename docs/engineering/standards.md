# Engineering standards

- Optimize for clarity, maintainability, accessibility, and user trust before cleverness.
- Keep modules cohesive and make dependencies explicit.
- Treat personal data, credentials, and logs as sensitive by default.
- Write tests around meaningful behavior, especially permissions, plan changes, and safety boundaries.
- Use plain, considerate language in all user-facing copy and error states.
- Keep interfaces observable: failures should be diagnosable without exposing private content.
- Prefer small, reviewable changes with documentation updated in the same change.
