# Accessibility
## Why
An inclusive Personal Operating System must be usable by people with diverse access needs.
## What
This document will define accessibility requirements for product design and implementation.
## How
Set an approved conformance target, include accessibility in design review, and test keyboard, screen-reader, contrast, motion, and responsive behavior.
## Future Considerations
Add component-level criteria when the design system exists.
